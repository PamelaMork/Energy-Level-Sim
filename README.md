# Energy-Level-Sim

An interactive hydrogen energy-level simulation built for teaching.

## What it does
- Lets students choose a starting and ending energy level
- Animates absorption and emission transitions
- Calculates ΔE, wavelength, and spectral region
- Displays absorption and emission spectra
- Accumulates spectral lines until Reset is pressed

## Live site
https://pamelamork.github.io/Energy-Level-Sim/

## Notes
This is a browser-based HTML/CSS/JavaScript simulation hosted with GitHub Pages.
